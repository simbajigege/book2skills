# 示例目录

这四张图来自 360 AI Native Training Deck 的 S06 与 S07，已整理为独立 SVG，作为语义提炼和视觉语法参考。原始教学页仍是课程事实来源；示例只用于复用构图方法。

## 1. 中心化任务派发

文件：`assets/examples/centralized-agent-dispatch.svg`

- 教学判断：中心 Agent 拆解任务并向下派发给多个子 Agent。
- 对象：一个父 Agent、三个子 Agent、六张任务纸。
- 关系：从中心到子节点的三条单向蓝色路径。
- 布局：上到下的树状层级。
- 视觉语义：父节点加粗边框；橙色折角代表任务；蓝色只用于派发方向。
- 适用：主从架构、管理层级、任务分解、单一调度中心。

## 2. 分布式自主认领

文件：`assets/examples/distributed-agent-claim.svg`

- 教学判断：多个平级 Agent 从公共任务环境自主认领工作。
- 对象：公共任务看板、五张任务纸、四个平级 Agent。
- 关系：从看板指向 Agent 区域的一条蓝色认领箭头。
- 状态：一张虚线任务纸表示尚待认领。
- 布局：左侧环境，右侧参与者。
- 适用：共享队列、任务市场、自治协作、拉取式工作流。

## 3. 老产品补建 LUI

文件：`assets/examples/gui-lui-retrofit.svg`

- 教学判断：已有 GUI 的老产品，需要后来补建机器可读的 LUI。
- 对象：GUI 页面线框、包含 `name` 与 `desc` 的 LUI 接口。
- 关系：标注“补建”的单向蓝色箭头。
- 状态：LUI 外框使用虚线，表示后来添加，而不是表示故障。
- 布局：左到右的时间与建设顺序。
- 适用：兼容层、旧系统改造、API 补建、人机界面差异。

## 4. 新产品同步设计 GUI 与 LUI

文件：`assets/examples/gui-lui-native.svg`

- 教学判断：新产品从一开始同步设计人类 GUI 与机器可读 LUI。
- 对象：同尺度、同完成度的 GUI 与 LUI。
- 关系：标注“同步设计”的双向蓝色箭头。
- 状态：两侧都使用实线，表示二者都是产品的一等界面。
- 布局：左右对等。
- 适用：双消费者系统、人机协同产品、同步契约、AI-native 产品设计。

## 如何使用示例

1. 先匹配关系类型，不按外观相似度选图。
2. 复制最接近的 `viewBox`、分组和线条语法。
3. 按新内容重写对象数量、标签、关系方向、状态线型、title、desc 和全部 ID。
4. 删除不支持新教学判断的细节；不要为了保留示例构图而扭曲语义。
5. 用 `scripts/validate-line-svg.mjs` 检查新文件或承载它的 HTML。
